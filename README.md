# 🏏 Boundary Boss – Cricket Auction Simulator

**Build your dream cricket team, compete in exciting auctions, and become the ultimate team owner!**

Boundary Boss is a browser-based cricket auction simulator designed for cricket fans. Experience the excitement of player auctions with IPL and World Auction modes.

## 🚀 Features

- 🌍 **World Auction:** Build your dream international cricket team.
- 🏆 **IPL Auction:** Experience an IPL-style player auction.
- 🔨 **Live Bidding:** Compete to purchase your favourite cricketers.
- 👥 **Multiple Teams:** Create and manage different teams.
- 🤖 **Computer Opponents:** Play against AI-style computer bidders.
- 🎮 **Friends Mode:** Enjoy pass-and-play auctions with friends.
- 💰 **Budget Management:** Track team purses and player purchases.
- 📋 **Player Database:** Explore international cricketers.
- ⭐ **Custom Players:** Add your own players.
- 💾 **Save & Load:** Save your auction progress.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🎯 Project Objective

The objective of Boundary Boss is to provide an entertaining and interactive cricket auction experience where users can build their dream squads, make bidding decisions, and manage their team budgets.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using Live Server or open directly in your browser.
5. Start your cricket auction!
